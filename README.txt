# Meeting Audio Converter

tl;dv에서 생성된 WebM 회의 녹음 파일을
ClovaNote에서 사용할 수 있는 M4A 파일로 변환하는 Windows 프로그램입니다.

## 주요 기능

- WebM → M4A 변환
- AAC 128kbps
- 원본 파일과 같은 폴더에 M4A 생성
- 로컬 환경에서 변환
- FFmpeg 기반

## 사용 목적

Google Meet
→ tl;dv Desktop
→ WebM 녹음
→ Meeting Audio Converter
→ M4A
→ ClovaNote

## 개발 환경

- Python
- Tkinter
- FFmpeg
- PyInstaller
